## Inheritance

- [CODE JENIS JENIS INHERITANCE](./CODE%20JENIS%20JENIS%20INHERITANCE/)
  - [Hierarchical Inheritance — Barbershop](./CODE%20JENIS%20JENIS%20INHERITANCE/Hierarchical%20Inheritance/)

Program Barbershop memakai `LayananBarber` sebagai parent class dan `PotongRambut` serta `PerawatanRambut` sebagai child class. Ada class `Pelanggan` dan program utama `Barbershop`. Fitur: daftar layanan, pemesanan dan diskon 10% untuk subtotal minimal Rp100.000.

### Cara menjalankan Barbershop

Buka terminal pada folder `CODE JENIS JENIS INHERITANCE/Hierarchical Inheritance`:

```bash
javac *.java
java Barbershop
```
